## 직접 카메라 확인
기존 관람 기록을 보존하려면 별도 시크릿 창에서 `http://localhost:5173/unanswered/`를 연다. `DEV` → `Final Report Sequence` → 영상 건너뛰기 → 각 보고서 단계의 다음 버튼 → 마지막 카메라 안내에서 `카메라로 보기`를 선택한다. 이 개발 경로는 해당 별도 창에 예시 관람 데이터를 사용한다. 영상이 준비되면 ‘당신이 찾던 사람은’ → 거울 화면 → ‘당신입니다.’ 순서로 재생한다.
