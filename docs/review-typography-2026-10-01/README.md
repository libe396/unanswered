## 범위와 한계
- 모바일 소리·기억·레이어 화면은 글자 크기를 보존하며 안전 영역 안에서 스크롤. 문장 선택은 기존 데스크톱 전용 안내 유지(모바일에서 선택하지 않음).
- 화면 검증은 Chromium. 실제 휴대폰/Safari, 물리 웹캠의 얼굴 구도, 인쇄 페이지 분할 및 모든 조건부 오류/보고서 분기는 이번에 실기 검증하지 않음. 기본 빈 상태와 빈 드로잉 확인 모달은 검증.
- 개발자 메뉴와 비표시 요소는 관람객 텍스트 통계에서 제외. SVG 선택 라벨은 별도 실측; Canvas에 표시 텍스트를 그리는 호출은 없음.
