# 빛의 흔적 이미지 교체 기록

2026-09-23. 원본: `Light_Archive_10_images.zip`.

## 연결과 복구

- ZIP의 `light-trace-NN-주제.png`를 번호로 확인하여 `src/assets/archive/light-trace-NN.png`로 복사했다. 모든 파일은 1254×1254이며 ZIP 원본과 바이트가 같다.
- `image-manifest.json`에 번호별 ZIP 파일명, 적용 파일명, SHA-256을 기록했다. 08은 wet-pavement, 09는 door-handle이다.
- `ARCHIVE_META`의 기존 제목과 순서, `IMAGE_01`~`IMAGE_10` ID를 유지한다. 메타데이터의 번호로 정확한 PNG 경로를 조회하며 파일 정렬 순서에 의존하지 않는다.
- 그리드·확대 선택·감각 선택·분석은 같은 이미지 객체를 사용한다. 저장 시 그 이미지 경로와 실제 분석 결과를 함께 기록하고, 보고서는 저장된 경로를 사용한다.
- 이전 `src/assets/archive/01.jpg`~`10.jpg`는 그대로 남아 있다. 이 폴더의 `.txt` 파일은 교체 직전 해당 소스의 사본이다. 복구할 때 현재 파일과 비교해 필요한 부분만 복원한다. 이후 작업을 덮어쓰지 않는다.
- 개발용 보고서 예시도 기존 05번 ID에 새 05번 사진을 사용한다. 개발용 MOCK 분석값은 예시이며 실제 관람 흐름에서는 사용하지 않는다.

## 실제 분석과 변환

`src/lib/imageAnalysis.js`는 브라우저 Canvas에서 긴 변 180px로 축소한 이미지의 픽셀을 읽는다. 사진별 사전 지정 분석 수치는 없다.

- 팔레트: RGB 버킷의 빈도·채도·밝기 점수로 후보를 추출하고 가까운 색의 픽셀 비중을 계산한다.
- 시작 위치: 밝은 연결 영역을 검출해 강도가 가장 큰 영역의 가중 중심을 사용한다. 검출 영역이 없으면 가장 밝은 픽셀로 대체한다. 실제 조명 기구의 위치를 식별하는 방식은 아니다.
- 밝기: 픽셀 RGB의 가중 평균 `(0.2126R + 0.7152G + 0.0722B) / 255`. 물리적 광량이나 노출값이 아니다.
- 흐림: 인접 픽셀의 밝기 경계 변화량으로 부드러움을 추정한다. 렌즈 흐림의 절대 측정값은 아니다.

`src/lib/lightRenderer.js`는 위 결과의 팔레트·비중·시작 위치·밝기·blurDensity·밝은 영역·구조를 그래픽에 사용한다. 선택 감각은 기존 방식대로 색·밝기·흐림을 추가 보정한다. 분석 화면과 팔레트 목록은 원본 픽셀 분석값이며, 생성 결과는 감각 보정이 적용된 예술적 표현이다. 결과 설명에 이 관계를 명시했다. 분석 및 렌더러 알고리즘 자체는 변경하지 않았다.

## 시각 처리

그리드·선택 미리보기·감각 미리보기·분석 사진은 정사각형, `object-fit: contain`, 중앙 정렬이다. 그리드의 인위적인 흐림·감광과 선택 시 확대 잘림을 제거해 원본 간 차이를 비교할 수 있게 했다. 선택 전 큰 미리보기의 흐림에서 선명해지는 연출은 유지했다.

## 검증

- 데스크톱 1440×1000: 실제 Landing → 엘리베이터 → 인트로 영상의 SKIP → 조사 시작 → 등록 → 빛의 흔적 경로로 진입했다. 08번 선택 → 평온 선택 → 분석 → 그래픽 → 기록 저장 → 소리의 단서까지 확인했다.
- 모바일 Chrome 에뮬레이션 390×844: 새로고침 후 Landing에서 같은 경로로 진입했다. 09번 선택 → 감각 선택 → 분석 → 그래픽 → 저장 → 소리의 단서까지 확인했다. 실제 휴대전화 기기 테스트는 아니다.
- 두 화면에서 그리드 10장 모두 정상 로드, 번호·제목 일치, 정사각형·contain·중앙 정렬을 확인했다. 감각·분석 사진과 저장된 경로도 선택 번호와 일치한다.
- 모바일의 긴 분석 화면이 중앙 정렬로 위쪽을 잘라내던 문제를 해당 Scene의 모바일 시작 정렬로 수정했다. 재검증 시 사진 상단 약 76px, 사진 304×304px, 문서 폭 390px로 전체 사진과 세로 스크롤이 정상이다.
- 브라우저 내장 연결 초기화가 실패해 기존 로컬 Headless Chrome의 별도 격리 컨텍스트에서 검증했다. 기존 Vite 5173 서버와 사용자 탭은 유지했다.
- `npm run build` 통과. 기존 500kB 초과 JavaScript 청크 경고는 남아 있다. `git diff --check` 통과. 커밋·푸시는 하지 않았다.
