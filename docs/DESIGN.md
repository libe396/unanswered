# DESIGN.md

# UNANSWERED Design Language

Version: 1.0

---

# Purpose

This document defines the visual language, interaction principles, and emotional direction of UNANSWERED.

It exists for AI coding agents, designers, and developers.

Whenever implementation decisions are unclear, this document takes precedence over personal preference.

The goal is consistency rather than creativity.

---

# Identity

UNANSWERED is not a website.

It is not a SaaS product.

It is not a dashboard.

It is not an application.

UNANSWERED is an interactive exhibition.

Every design decision should reinforce this identity.

If an interface element makes the experience feel like software instead of an exhibition, redesign it.

---

# Experience

Visitors should feel like they are walking through a quiet physical exhibition.

The interface should gradually disappear.

The exhibition should become the primary experience.

Visitors should remember

- the questions
- the atmosphere
- the lighting
- the silence

They should not remember

- buttons
- cards
- menus
- navigation
- layouts

---

# Design Philosophy

## Space before Interface

The exhibition space is always more important than UI.

Never place interface elements simply because space is available.

Empty space is intentional.

Whitespace communicates atmosphere.

---

## Atmosphere before Decoration

Do not decorate.

Design atmosphere.

Every visual element should support emotion.

Nothing should exist purely because it looks beautiful.

---

## Questions before Features

Questions are the center of every screen.

UI exists only to support questions.

Never compete with them.

---

## Reflection before Completion

Do not encourage speed.

Do not reward completion.

The exhibition values reflection over progress.

---

## Interpretation before Evaluation

AI never evaluates.

AI never judges.

AI never categorizes people.

AI simply reconstructs the visitor's experience.

---

# Emotional Direction

The exhibition should consistently communicate:

- Quiet
- Calm
- Warm
- Reflective
- Gentle
- Spacious
- Honest

Avoid

- Exciting
- Energetic
- Competitive
- Playful
- Busy
- Corporate

---

# Spatial Principles

Always think in rooms instead of pages.

Every Scene represents a physical exhibition space.

Entering another Scene should feel like entering another room.

Never think

"Next Page"

Always think

"Next Space"

---

# Composition

Prefer asymmetrical layouts.

Avoid perfect symmetry unless intentionally required.

Keep a single visual focus.

Large margins are encouraged.

Content width should remain narrow enough to encourage reading.

Whitespace is part of the content.

---

# Color

Light communicates emotion.

Color only supports light.

Prefer

- Warm neutrals
- Soft gray
- Paper tones
- Stone tones
- Dust colors

Avoid

- Neon
- Saturated colors
- Rainbow palettes
- Bright gradients

Never use pure black.

Never use pure white.

---

# Lighting

Lighting is a design system.

It is not decoration.

Lighting should

- guide attention
- communicate emotion
- define depth
- slow down interaction

Lighting transitions should always be slower than interface transitions.

Avoid flashing.

Avoid rapid brightness changes.

---

# Motion

Motion should resemble breathing.

Preferred animations

- Fade
- Dissolve
- Blur
- Opacity
- Slow Scale
- Soft Translation

Avoid

- Bounce
- Elastic
- Spin
- Shake
- Overshoot
- Dramatic zoom

If unsure,

make the animation slower.

---

# Typography

Typography should feel literary rather than technical.

Titles should feel like exhibition signage.

Body text should feel like reading a printed exhibition guide.

Prefer

high readability

comfortable spacing

generous line height

Avoid

compressed text

large bold paragraphs

center aligned long text

---

# Components

Every component should disappear into the exhibition.

Components should never attract unnecessary attention.

Buttons should feel secondary.

Cards should resemble printed paper.

Inputs should resemble writing.

Progress indicators should feel subtle.

---

# Layout

Each screen should communicate one idea.

Do not overload screens.

Every Scene should contain

- one emotional goal
- one primary question
- one interaction

---

# Interaction

Interaction should never feel urgent.

Hover

soft brightness

Click

small opacity change

Typing

continuous

Scrolling

slow

Transitions

quiet

---

# AI Report

The report is part of the exhibition.

It is not a result screen.

It is not analytics.

It is not a dashboard.

It should feel like reading a curator's note.

Avoid

"You are..."

Prefer

"During the exhibition..."

"In this space..."

"Throughout your journey..."

---

# Accessibility

Accessibility is mandatory.

Support

- Keyboard navigation
- Visible focus
- Reduced motion
- Semantic HTML
- Screen readers

Never sacrifice accessibility for aesthetics.

---

# Performance

Atmosphere depends on performance.

Target

- Fast initial load
- Stable transitions
- Smooth animation

Avoid layout shifts.

Avoid blocking rendering.

Preload critical assets.

---

# Design Tokens

Never hardcode values.

Always use semantic tokens.

Examples

Good

color.paper

color.shadow

motion.slow

spacing.large

radius.medium

Bad

#FFFFFF

16px

0.3s

---

# Component Rules

Every component must

- have one responsibility
- be reusable
- be composable
- be testable
- use semantic naming

Never duplicate components.

---

# Naming

Good

SceneContainer

QuestionCard

LightingLayer

TransitionOverlay

ReportViewer

Bad

Wrapper

Box

Container2

SectionFinal

CardNew

---

# Anti Patterns

Never generate

- Dashboard layouts
- Landing pages
- Marketing sections
- Pricing tables
- Analytics panels
- Floating Action Buttons
- Floating Chat Widgets
- Notification badges
- Confetti
- Achievement systems
- Progress rewards
- Glassmorphism-heavy interfaces

Avoid visual styles that resemble

- Banking applications
- Productivity software
- CMS dashboards
- Social media feeds

---

# AI Generation Rules

When generating UI

Always

- prioritize atmosphere
- preserve whitespace
- minimize interface
- use slow motion
- maintain visual consistency
- keep one focal point
- respect emotional tone

If uncertain

remove elements instead of adding new ones.

Minimalism is preferred over decoration.

---

# Final Principle

Before generating any interface, ask:

"Does this feel like software?"

If the answer is yes,

simplify.

Reduce interface.

Increase atmosphere.

The best interface is the one visitors barely notice.
