# 문장 인트로·소리 선택 정리

변경 파일:
- `src/scenes/SentenceCluesScene.tsx`: 중앙 인트로, 저장된 색·소리·사물 요약, 확정 안내/버튼. 인트로의 자동 서술문/아코디언/3개 미리보기 제거. 공용 sentenceNarrative 모듈은 보존.
- `src/scenes/SentenceCluesScene.css`: 인트로 중앙 정렬, 요청된 데스크톱 크기의 20개 문장 전체 표시. 최소 지원 크기 1100×650에 맞춘 패딩·행간·중복 정보 조정. 넘치는 문장이나 선택지를 숨기지 않음.
- `src/scenes/SoundCluesScene.tsx`: 최종 선택 체크를 소리 이름 옆에 배치. 선택 버튼과 재생 상태의 의미를 구분.
- `src/scenes/SoundCluesScene.css`: 작은 데스크톱 높이에서 안내/선반/플레이어/행동 영역 여백 축소. 공통 헤더와 하단 진행바 사이 공간 보존.

검증:
- 실제 Chromium 콘텐츠 viewport 1440×900, 1366×768, 1100×650.
- 인트로, 문장 0개/5개 선택: 20개 문장 전체 및 다음 버튼 표시. 스크롤·잘림 없음.
- 최소 3개, 최대 5개 정책 확인. 2개일 때 진행 불가, 3개일 때 진행 가능, 5개일 때 미선택 문장 추가 선택 제한.
- 기록 없는 인트로에서 색·소리·사물 없음 표시 확인.
- 기록 확인 → 빈칸 입력 → 기록 완료 → 저장 → Zone 07 진입 및 저장된 3개 문장 ID/입력 답변 확인.
- 빗소리 선택 상태를 유지하면서 지하철 재생. 재생 항목이 최종 선택을 변경하지 않음.
- 최종 소리 레이아웃 측정은 verification.json 참고.
- npm run build 통과. 기존 번들 크기 경고 유지.

테스트는 별도 브라우저 컨텍스트에서 수행했다. 수집 단서가 있는 캡처는 개발용 예시 관람 데이터로 확인했으며 사용자의 관람 데이터는 변경하지 않았다. 다른 Zone, 저장 키, 오디오 7개/ID, 관람 추적 및 선택 후 복원 로직은 보존했다. 기존 staged/unstaged/untracked 작업을 유지했고 commit/push하지 않았다.
